# Job Description — Senior Backend Engineer, Platform Team

**Location:** Bengaluru (hybrid — interview is in-person where possible)
**Experience level:** 5+ years

## Must-have skills

- Python
- Kubernetes
- System Design
- SQL

## Nice-to-have skills

- Service Mesh (Istio)
- Mentoring
- CI/CD (Jenkins)

## Role summary

We're hiring a senior backend engineer to own reliability and scale for our
platform team — the same team that runs our core data ingestion and service
mesh. The role owns production deployment pipelines and partners closely
with SRE on on-call.

## What we're screening for

- Demonstrated ownership of a production Kubernetes deployment pipeline
- Comfort with distributed systems failure modes, not just happy-path design
- SQL fluency for data-quality and operational debugging, not just app code
- Bonus: experience mentoring junior engineers, since this role will grow
  into a team-lead track within a year
